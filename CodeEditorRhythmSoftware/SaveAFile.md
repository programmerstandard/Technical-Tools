# Save A File In Code Editor by Rhythm Software.

1. Do activities in [CreateANewFile.md](CreateANewFile.md).
2. Type your contents inside the text area.
3. Tap on Folder icon inside the Top toolbar.
4. Tap on Save icon submenu.
5. Input File Name and File Extension.
6. Determine the file location.
7. Tap on the Save button.
