# Start MariaDb Server

* You must start the 'Apache' web server as explained in the previous lesson, on the [StartTheApacheServer.md](StartTheApacheServer.md)
* At the top row ( green bar ). In the third tab (MariaDb Sql Server). Click 'Start' button on the 'Service' row.
* After your 'MariaDb SQL Server' started. Take a note for Address that will be use in MySql client.
